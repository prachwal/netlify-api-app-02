# Cline Configuration

## Project Setup

- This is a React application using Vite, TypeScript, and Ant Design (antd).
- Deployed on Netlify.
- Local development: `npm run dev`
- Build: `npm run build` (optimized with code splitting and lazy loading)
- File merging: `npm run merge` (excludes .cline.md from output)
- **Theme Configuration**: ConfigProvider is set up at the root level in `src/main.tsx` to ensure notifications and all components use the correct theme
- **Performance**: Code splitting with manual chunks for vendors and lazy-loaded routes
- **Bundle Optimization**: Use specific Ant Design imports (e.g., `import Button from 'antd/es/button'`) instead of barrel imports to enable tree-shaking. Removed manual `antd-vendor` chunk from Vite config for better code splitting and reduced bundle sizes.

## Coding Standards

- Use TypeScript for all components and utilities.
- Follow React best practices, including hooks.
- Use antd components for UI elements instead of custom CSS where possible.
- **State Management**: Use Redux Toolkit with settingsSlice for theme and language (persistent in localStorage)
- **Ant Design API Updates (to avoid deprecation warnings):**
  - Use `orientation` prop instead of deprecated `direction` prop for antd Space components
  - Use `styles.content` prop instead of `valueStyle` for antd Statistic components
  - Use `title` prop instead of deprecated `message` prop for notification components
  - Use `size` prop instead of deprecated `width` prop for antd Drawer components
  - Use `title` prop instead of deprecated `message` prop for antd Alert components
  - Use `App.useApp()` to access `message`, `notification`, and `modal` for proper theme context consumption
- Maintain clean, readable code with proper commenting.

## Notification Components

- `message`: Small notifications appearing at the top center
  - Use: `message.success()`, `message.error()`, `message.warning()`, `message.info()`, `message.loading()`
  - **IMPORTANT**: Must use `App.useApp()` to consume dynamic theme context
  - **Fix**: Changed from static `import { message } from 'antd'` to `const { message } = App.useApp()` in components to fix theme inheritance issues
- `notification`: Larger floating notifications that can appear in corners
  - Use: `notification.success()`, `notification.error()`, `notification.warning()`, `notification.info()`, `notification.open()`
  - **IMPORTANT**: Must be called within App component context to consume dynamic theme
  - Use `title` prop instead of deprecated `message` prop
  - For custom notifications, use `notification.open({ title: '...', description: '...' })`

## File Merging

- The project's merge script (`scripts/merge-files.js`) combines multiple files with headers and footers.
- **IMPORTANT**: Do NOT include `.cline.md` in the merged output - it contains project-specific configuration and comments that should not be part of file merges.

## State Management

- **Redux Toolkit**: Used for global state management
- **settingsSlice**: Handles theme (light/dark/system) and language (en/pl) with localStorage persistence
- **counterSlice**: Manages counter state
- All state is typed with TypeScript interfaces
